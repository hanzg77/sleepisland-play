# 竖屏几何机关乐器 v4

V4 是独立入口，不覆盖 V3。它把基础因果改为：**暗格静止无声，亮起才开始运动并进入声音时间轴**。

## Phase 4.1

- 1080×1920、9×16 暗色竖屏，共 144 个近方格；高潮严格保持 128 个亮态声部，余下 16 个暗格保留视觉层级。
- 五类组件配额为钟摆 30、贴墙滑块 28、八音盒转盘 28、毛毡软槌 30、丝带轨道球 28。
- 每次激活使用组件局部时间轴：`darkFrozen → anticipate → active → settle → complete`。
- 暗格的姿态不读取全局时间，不产生任何声音事件。
- 单格一旦激活，会连续运行 1–4 个整数完整周期；亮着就一直运动并按每周期物理地标发声，最后精确回到初始姿态后才熄灭。钟摆至少运行两周期，第三次过中线不会漏声。
- 默认自动生长使用 `1→2→4→8→16→24→36→48→64→80→96→112→128`，在 0–90 秒间按空间错落进入；完成整数周期的旧组件与暗格换班，当前亮态人口保持目标值。
- 128 个亮格全部是实际演奏者。高密度时事件和连续摩擦层采用平方根响度补偿，不把旧 64 声部的总响度直接翻倍。
- 墙图先于组件生成：滑块只沿 1–3 段连续实墙移动；软槌连杆、曲线端口和钟摆支点全部固定在真实存在的墙边。
- 滑块新增随速度变化的连续材质摩擦层，并在端点与转角加入木、毡、陶瓷或金属触碰声；暗态立即停止对应摩擦节点。
- “自动生长 / 点击试听”模式切换会先让已开始的动作和尾音完整结束；尚未开始的未来循环可以取消，但进行中的 activation 不会被淡出、重置或截断。
- 点击试听直接按 Canvas 的 9×16 方格命中。点哪个，哪个从 `anticipate` 开始运行完整的整数周期组；进行中重复点击同一格不重触发。
- 最多 6 个 one-shot 同时演奏；第 7 个起按点击顺序 FIFO 排队，画面以进度环和队列序号显示状态。切回自动生长时，所有 active 与 queued 试听都完成后才从 1 格重新开始。

## 使用

```text
index.html?seed=v4-growth-preview
```

直接进入点击试听：

```text
index.html?seed=v4-growth-preview&mode=interactive
```

- 刷新默认带声音意图，浏览器允许 autoplay 时直接出声；若浏览器暂停 AudioContext，按钮会显示“点一下开声”，首次点击画面或控件会在同一手势恢复声音。使用 `&sound=off` 可明确关闭默认声音。
- “◎ 自动生长 / ☝ 点击试听”：切换两种模式；按钮手势同时预热 Web Audio。
- 点击试听时直接点击或触摸任意格。进度环走完前该格不会再次触发，超过 6 个的请求会显示排队序号。
- “暂停”：冻结共享逻辑时间，因此不会跳过动作或声音事件。

自动化契约覆盖完整周期闭合、128 声部增长、30/60fps 确定性、真实墙锚、滑块多边路线、第三次钟摆过中线、6 声部点击 FIFO 与默认声音策略。

## 三分钟离线导出

普通页面仍在约 90 秒达到 128 个亮态组件；正式成片只有显式 export performance 使用 128 秒达峰、168–178 秒完整周期退场、178–180 秒全暗的独立弧线。

```bash
node render-video.mjs --duration 180 --seed v4-three-minute --output exports/kinetic-maze-v4-3min.mp4
```

脚本在 Node VM 中复用同一状态机，以 30fps 软件栅格/定长 RGB rawvideo pipe 生成 1080×1920 H.264 画面，并离线合成 48kHz stereo PCM 后编码为 AAC。无需浏览器、Playwright 或屏幕录制。
